# אברהם העברי - אנדרואיד

אפליקציית Android אופליין לחלוטין, מבוססת מילות מפתח וטריגרים לביצוע פעולות ופתיחת אפליקציות/מסמכים.

## מצב הפרויקט
- עברית + English עם RTL/LTR.
- ללא INTERNET permission וללא שירות AI/שרת.
- פתיחת אפליקציות מותקנות דרך PackageManager.
- חיפוש קבצים דרך אינדקס תיקיות שהמשתמש בוחר + fallback לבוחר המסמכים.
- תיקון שגיאות כתיב עד מרחק Levenshtein של 2.
- זיהוי פעולה/פתיחה לפי מצב שנבחר ולפי פעלי פעולה מפורשים.
- קיצור נגישות אופציונלי: + ואז - בתוך שנייה, לפתיחה מהירה.
